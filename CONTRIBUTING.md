# Contributing

🇬🇧 **English**

Thanks for looking.

**Found a bug?** Open an [Issue](../../issues). Please include your operating
system, your DaVinci Resolve version (and whether it is Studio or Free), the
script version, and the log file if you have it. The 🐛 button inside the script
collects all of this for you.

**Spotted a bad translation?** The interface and the guide exist in 12 languages,
generated automatically and checked only for structure — so some of them are
likely clumsy or wrong. Corrections are genuinely welcome, and are the easiest
useful thing to contribute. Open an Issue with the language, the text as it is
now, and what it should say. Please do not edit `docs/` or `scripts/strings/`
directly in a pull request: both are generated from a translation source, and an
edit there would be overwritten the next time they are rebuilt.

**Did it run on the free version of Resolve?** That is not verified. If you tried
it, say so in an Issue — it answers a question in the README for everyone.

**Have an idea?** Open an Issue and describe the problem you are trying to solve,
not only the feature you have in mind. Most good ideas here came from someone
describing their workflow.

**Want to send code?** Pull requests are welcome. Keep them small and focused:
one change per request, so I can actually read it.

**Worth knowing:** I am a film editor, not a professional developer. This code
works and is used on real edits, but it does not follow the conventions of a
software project — there are no tests, the comments are in Italian, and some
choices are pragmatic rather than elegant. If that bothers you, you are in the
wrong repository.

I reply when editing work allows. It can take a while.

🇮🇹 **Italiano**

Grazie per essere passato.

**Hai trovato un bug?** Apri una [Issue](../../issues). Indica il sistema
operativo, la versione di DaVinci Resolve (e se è Studio o gratuita), la versione
dello script, e il file di log se ce l'hai. Il pulsante 🐛 dentro lo script
raccoglie tutto da solo.

**Hai visto una traduzione sbagliata?** L'interfaccia e la guida esistono in 12
lingue, generate automaticamente e verificate solo nella struttura — quindi
alcune saranno goffe o sbagliate. Le correzioni sono davvero benvenute, ed è la
cosa utile più semplice da contribuire. Apri una Issue con la lingua, il testo
com'è adesso, e cosa dovrebbe dire. Per favore non modificare direttamente
`docs/` o `scripts/strings/` in una pull request: sono entrambi generati da un
documento di traduzione, e una modifica lì verrebbe persa alla prima
rigenerazione.

**L'hai fatto girare sulla versione gratuita di Resolve?** Non è verificato. Se
l'hai provato, scrivilo in una Issue — risponde a una domanda che nel README è
ancora aperta, per tutti.

**Hai un'idea?** Apri una Issue e descrivi il problema che vuoi risolvere, non
solo la funzione che hai in mente. Le idee migliori qui sono nate da qualcuno che
raccontava come lavora.

**Vuoi mandare del codice?** Le pull request sono benvenute. Tienile piccole e su
una cosa sola, così riesco a leggerle davvero.

**Da sapere:** sono un montatore, non uno sviluppatore di professione. Questo
codice funziona e viene usato su montaggi veri, ma non segue le convenzioni di un
progetto software — non ci sono test, i commenti sono in italiano, e alcune
scelte sono pratiche più che eleganti. Se la cosa ti disturba, hai sbagliato
repository.

Rispondo quando il lavoro di montaggio lo permette. Può volerci tempo.
