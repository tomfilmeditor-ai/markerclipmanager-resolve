มันทำอะไร
---------
หน้าต่างเดียวเพื่อดู และจัดการมาร์กเกอร์ทั้งหมดในไทม์ไลน์ Resolve: 
มาร์กเกอร์ไม้บรรทัด (ระดับไทม์ไลน์) และมาร์กเกอร์ที่วางไว้บนคลิปแต่ละรายการบน
แทร็กวิดีโอและเสียงทั้งหมด

สำหรับแต่ละมาร์กเกอร์จะแสดง: กราฟิกมาร์กเกอร์ (รูปแบบเดียวกับ Resolve)
แทร็ก TC เข้า TC ออก ระยะเวลา สี ชื่อ คำสำคัญ หมายเหตุ

คุณลักษณะ
---------
- เลือกมาร์กเกอร์หนึ่งรายการหรือมากกว่า แล้วเปลี่ยนสี เปลี่ยนแทร็ก
  (รวมถึงย้ายไปยังหรือออกจากไม้บรรทัด "TIMELINE") หรือลบ
- แก้ไขชื่อ คำสำคัญ และหมายเหตุได้โดยตรงในตาราง (ดับเบิลคลิก)
  และใช้กับมาร์กเกอร์หลายรายการที่เลือกไว้พร้อมกันได้
- ปุ่ม Delete ทำงานเหมือนปุ่มลบ พร้อมการยืนยันที่คุณปิดได้
- เลิกทำและทำซ้ำด้วย Cmd+Z / Ctrl+Z และมีแผง History: ดับเบิลคลิกที่ขั้นตอน
  ก่อนหน้าเพื่อย้อนกลับไปที่จุดนั้นได้ทันที ครอบคลุมเฉพาะเซสชันปัจจุบัน
  และจะถูกล้างเมื่อคุณปิดสคริปต์
- กรองตามสี แทร็ก ผู้เขียน/ชื่อ หรือคำสำคัญ
- ส่งออกและนำเข้ามาร์กเกอร์เป็น CSV
- คลิกที่แถวใดแถวหนึ่ง: เพลย์เฮดของไทม์ไลน์จะกระโดดไปที่มาร์กเกอร์นั้น
- อินเทอร์เฟซมี 12 ภาษา: เริ่มต้นด้วยภาษาของระบบหากมีให้ตรงกัน มิฉะนั้น
  จะเป็นภาษาอังกฤษ และเปลี่ยนได้จากเมนูด้านบนของหน้าต่าง
  (มีผลเมื่อเริ่มสคริปต์ใหม่)

ความต้องการ
-----------
- DaVinci Resolve 19/20 (macOS)
- Python 3 ติดตั้งในระบบ
- PySide6 (ติดตั้งโดยอัตโนมัติโดยสคริปต์การตั้งค่าด้านล่าง — ไม่จำเป็นต้องใช้
  ขั้นตอนด้วยตนเอง)

การติดตั้ง (ครั้งเดียว)
-----------------------
1. ดาวน์โหลดตัวติดตั้งสำหรับระบบของคุณ
2. macOS: คลิกขวาที่ไฟล์ .command แล้วเลือก "เปิด" ไม่ใช่ดับเบิลคลิก
   เพราะไฟล์ไม่ได้เซ็นด้วยใบรับรองนักพัฒนาของ Apple ทำให้ macOS บล็อกไว้
   Windows: ดับเบิลคลิกที่ไฟล์ .cmd หาก SmartScreen เตือน ให้เลือก
   "ข้อมูลเพิ่มเติม" แล้วเลือก "เรียกใช้ต่อไป"
3. ตัวติดตั้งจะคัดลอกไฟล์ แล้วเตรียมสภาพแวดล้อม Python ที่สคริปต์ต้องใช้
   (ขั้นตอนนี้ต้องใช้อินเทอร์เน็ตและใช้เวลาราวหนึ่งนาที)
4. หากขั้นตอนที่สองไม่สำเร็จ เช่น ไม่มีการเชื่อมต่อ หรือไม่มี Python
   ไฟล์ก็ยังติดตั้งถูกต้องอยู่ดี ให้เปิดโฟลเดอร์ที่ติดตั้งแล้วเรียกใช้
   "MarkerClipManager_Setup.command" (macOS) หรือ
   "MarkerClipManager_Setup_Windows.cmd" (Windows) เมื่อสะดวก
5. เสร็จแล้ว การอัปเดตติดตั้งด้วยวิธีเดียวกัน ทับบนเวอร์ชันก่อนหน้า
   และการตั้งค่าของคุณจะไม่ถูกแตะต้อง

การใช้งาน
---------
ใน DaVinci Resolve: Workspace > Scripts > Comp > MarkerClipManager > MarkerClipManager
(สคริปต์อยู่ในโฟลเดอร์ย่อย "MarkerClipManager" ภายใน Comp ดังนั้นจึงปรากฏในเมนู
เป็นเมนูย่อยที่มีชื่อเดียวกัน)

ข้อจำกัดที่ทราบ
---------------
- มาร์กเกอร์ในตารางเป็นไอคอนที่สร้างขึ้นใหม่วาดโดยสคริปต์ ไม่ใช่ไอคอนอย่างเป็นทางการของ
  Resolve (ไม่เปิดเผยโดย API) สีเป็นค่าเฮกซ์แดซิมัลที่ให้โดยผู้ใช้อย่างแน่นอน — เฉพาะรูปแบบไอคอน
  ที่ยังคงเป็นการประมาณ
- "คำสำคัญ" ไม่ใช่ฟิลด์มาร์กเกอร์เนทีฟ Resolve: มันถูกเก็บไว้ในฟิลด์มาร์กเกอร์ภายใน
  (customData) ซ่อนอยู่จากแผงมาร์กเกอร์เนทีฟ Resolve — อ่านได้/เขียนได้เฉพาะโดยสคริปต์นี้
- โค้ดเวลาอ่านfps และโหมด Drop Frame/Non-Drop Frame โดยตรงจากไทม์ไลน์ที่ใช้งานของโครงการ
  (29.97 และ 59.94 DF ถูกจัดการอย่างถูกต้องด้วยอัลกอริทึม SMPTE มาตรฐาน); บน fps ที่ไม่ใช่มาตรฐาน
  คณิตศาสตร์ยังคงเป็นการประมาณ
- การนำเข้า/ส่งออก EDL ไม่ได้รับการจัดการโดยสคริปต์นี้: ใช้ฟีเจอร์เนทีฟของ Resolve
  (Timeline > Markers > Export/Import)
- การย้ายมาร์กเกอร์ไปยังแทร็กวิดีโอ/เสียงต้องการให้คลิปมีอยู่แล้ว
  ที่ตำแหน่งนั้น
