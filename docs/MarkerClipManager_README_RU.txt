MarkerClipManager — Менеджер маркеров временной шкалы и клипов для DaVinci Resolve
==================================================================================
Author: Tommaso Feraboli — Film Editor
Version: 1.4.6
MIT License — see the script header

ЧТО ОНА ДЕЛАЕТ
--------------
Единое окно для просмотра и управления всеми маркерами на временной шкале Resolve: 
маркеры линейки (уровень временной шкалы) и маркеры, размещенные на отдельных клипах,
на каждой видео- и аудиодорожке.

Для каждого маркера отображается: график маркера (та же форма, что и Resolve),
дорожка, TC начало, TC конец, длительность, цвет, имя, ключевое слово, примечание.

ОСОБЕННОСТИ
-----------
- Выберите один или несколько маркеров и измените цвет, измените дорожку
  (в том числе на линейку "TIMELINE" и обратно), удалите
- Редактируйте Имя, Ключевое слово и Примечание прямо в таблице (двойной
  щелчок), в том числе сразу у нескольких выбранных маркеров
- Клавиша Delete делает то же, что и кнопка удаления, с подтверждением,
  которое можно отключить
- Отмена и повтор по Cmd+Z / Ctrl+Z, плюс панель History: двойной щелчок по
  предыдущему шагу возвращает прямо к нему. Это работает только в текущем
  сеансе и очищается при закрытии скрипта
- Фильтр по цвету, дорожке, автору/имени или ключевому слову
- Экспорт и импорт маркеров в CSV
- Щелчок по строке: курсор воспроизведения переходит к этому маркеру
- Интерфейс доступен на 12 языках: запускается на языке системы, если он есть
  среди них, иначе на английском, и его можно сменить в меню вверху окна
  (вступает в силу после перезапуска скрипта)

ТРЕБОВАНИЯ
----------
- DaVinci Resolve 19/20 (macOS)
- Python 3 установлен в системе
- PySide6 (устанавливается автоматически скриптом настройки ниже — не требуются
  ручные шаги)

УСТАНОВКА (один раз)
--------------------
1. Скачайте установщик для своей системы
2. macOS: щёлкните по файлу .command ПРАВОЙ КНОПКОЙ и выберите «Открыть» — не
   двойным щелчком, который macOS блокирует, потому что файл не подписан
   сертификатом разработчика Apple
   Windows: дважды щёлкните по файлу .cmd; если SmartScreen предупредит,
   выберите «Подробнее», затем «Выполнить в любом случае»
3. Установщик копирует файлы, а затем готовит среду Python, нужную скрипту
   (для этой части требуется интернет, занимает около минуты)
4. Если вторая часть не удалась — нет соединения или не установлен Python —
   файлы всё равно установлены правильно: откройте папку установки и запустите
   "MarkerClipManager_Setup.command" (macOS) или
   "MarkerClipManager_Setup_Windows.cmd" (Windows), когда будет возможность
5. Готово. Обновления устанавливаются так же, поверх предыдущей версии, и ваши
   настройки остаются нетронутыми

ИСПОЛЬЗОВАНИЕ
-------------
В DaVinci Resolve: Workspace > Scripts > Comp > MarkerClipManager > MarkerClipManager
(скрипт находится в подпапке "MarkerClipManager" внутри Comp, поэтому появляется
в меню как подменю с тем же именем)

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
---------------------
- Маркер в таблице — это пересозданный значок, нарисованный скриптом, а не
  официальный значок Resolve (не предоставляется API). Цвета — это точные
  шестнадцатеричные значения, предоставленные пользователем — только форма значка
  остается приближением
- "Ключевое слово" не является встроенным полем маркера Resolve: оно хранится
  во внутреннем поле маркера (customData), невидимом для встроенной панели маркеров
  Resolve — читается/записывается только этим скриптом
- Временной код читает fps и режим Drop Frame/Non-Drop Frame непосредственно из
  активной временной шкалы проекта (29.97 и 59.94 DF правильно обрабатываются
  со стандартным алгоритмом SMPTE); при нестандартном fps математика остается приблизительной
- Импорт/экспорт EDL не обрабатывается этим скриптом: используйте встроенную
  функцию Resolve (Timeline > Markers > Export/Import)
- Перемещение маркера на видео/аудиодорожку требует, чтобы клип уже существовал
  в этой позиции
